# Security and Data-Release Boundary

This repository intentionally excludes all production API keys, knowledge-base
tokens, cloud-storage credentials, internal endpoints, tenant identifiers,
private Web corpora, and raw experiment logs.

The poisoning documents generated by this code are for controlled, isolated
evaluation environments only. Do not publish generated pages to the public Web,
impersonate real organizations, or use the pipeline to manipulate deployed
search or recommendation systems. Generated URLs are offline labels and must
never be fetched or registered.

Before publishing a fork, run:

```bash
bash scripts/scan_secrets.sh
```

Publish this directory as a new standalone repository. Do not preserve or push
the parent research repository's Git history, because files removed from the
working tree can remain recoverable from earlier commits.

If a credential was ever committed to Git history, removing it from the current
file is insufficient. Revoke it and rewrite the repository history before
release.
